# 眼动控制原型使用说明

版本：0.10.0-prototype

本版本在迁移安卓工程中新增统一首页和眼动控制原型，保留原脑电采集入口。应用包名为`com.bci.glasses.prototype`，与原工程的`com.bci.glasses`区分，避免覆盖原采集App。

## 当前功能

- 八方向环形显示、四频率两相位配置，三候选内频率唯一。
- 触控或鼠标模拟注视；落点会保持为模拟视线，便于操作右侧面板。
- 稳定注视进入三候选，组内精选择保持当前组，稳定看向另一组才切换。
- 人工注入选择与确认，进入单目标反馈和虚拟末端持续移动。
- 模拟注意力下降且有效视线移开，正常停止并恢复八方向。
- 模拟眼动丢失、对象失跟、超出显示范围；旧候选失效，恢复后需重新开始。
- 后台停止、布局变化停止、虚拟工作区边界停止。
- 刺激参数配置、输入诊断、JSONL日志及系统文件选择器导出。

尚未接入真实眼动SDK、真实脑电分类、注意力或MI算法、真实对象锚定、放大器直连和机械臂。当前确认由人工事件注入，虚拟对象采用简化二维工作区，不能作为真人脑机控制或真实AR附着验收。

设计约束：不加入脑电判断质量门。现有采集诊断仅作记录与分析，不以脑电质量分数、通道数或幅值阈值作为控制放行条件。

## 操作步骤

1. 安装APK，打开“BCI 眼动原型”，选择“进入眼动控制原型”。
2. 点击“开始模拟”。默认静态预览，闪烁关闭。
3. 点击某个方向块并等待，或用鼠标移动到该块，稳定约400ms后保留该方向及两个相邻方向。
4. 在当前三个候选之间移动模拟视线，候选组不变；稳定看另一组约500ms后切换。当前数值为可调整的软件演示参数，不是实测眼动阈值。
5. 视线保持在当前候选中的一个方向，点击“注入选择与确认”。这会人工注入判决事件，并只驱动屏幕内虚拟末端。按钮不是最终产品确认方式。
6. 执行中勾选“模拟注意力下降”，再把模拟视线移到方向区外，例如中央工作区；共同条件持续约400ms后停止并恢复八方向。只有其中一个条件时，不触发正常退出。
7. “停止模拟”立即停止。要继续可重新开始；“重置位置”停止并把虚拟末端归零。
8. “模拟眼动丢失”会暂停虚拟移动和新增判决，超过约600ms后中断。无效眼动不计为主动看离。实际设备的动作许可与失效期限仍需实测设计。
9. 模拟对象失跟或超出显示范围会中断，清除故障开关后重新开始，不自动续跑。
10. “刺激参数 / 编码配置”可输入四种不同频率、目标尺寸与亮度上限；打开设置先停止动作，修改后重新开始。配置并不保证某个设备能产生对应的实际光学波形。
11. “眼动接入诊断”展示模拟来源、坐标和数据年龄；原生SDK与设备校准明确显示未连接或未验证。
12. “导出日志”通过安卓系统文件选择器保存JSONL，离开前台时模拟与刺激会停止。

窄屏时面板在下方，横屏时在右侧；面板可以滚动。控制Activity优先横屏，具体形态还需眼镜实测。

## 刺激时序

显示在Choreographer帧回调下运行，采用统一单调帧时钟计算亮度；候选切换保留全局相位，并更新候选版本。默认频率为60/7、12、10、15Hz，各频率在相对位置复用，后四方向相位为π。实际显示仍需光学测量。

默认关闭闪烁，开关用于显式启用刺激；静态预览与闪烁都执行同样的候选逻辑。绘制显示软件帧回调计数和估计漏帧，它们不代表光学输出已验收。

## 日志

每个会话写到应用私有目录`files/control_sessions/control_<timestamp>.jsonl`。记录输入来源、对象、候选版本、候选集合、选择、动作状态、虚拟末端位置、模拟眼动与注意力状态、刺激计划和配置。运行时每约250ms记录一次观测快照，这是软件诊断采样，不是原生眼动原始数据。

ADB调试导出需使用新包名，例如：

```powershell
adb shell run-as com.bci.glasses.prototype ls files/control_sessions
```

原采集导出工具若用于本版本，`--package`需指定`com.bci.glasses.prototype`。采集模式仍使用原有Recorder配置，需要实际设备后验证。

## 开发与验证

控制状态机和输入契约集中在`ControlSession.kt`及`ControlGazeProvider.kt`；安卓界面为`ControlPrototypeActivity.kt`、`ControlSceneView.kt`和`PrototypeHomeActivity.kt`。

新增16项状态机测试，覆盖所有方向、环形邻接、候选内频率、组内保持、边界容忍、跨组版本、确认绑定、过期输入、跟踪和显示失效、正常退出共同条件、调度中断和斜向速度一致性。既有采集与刺激测试继续保留。

构建命令：

```powershell
.\scripts\build-debug.ps1
```

首次构建需要联网获取依赖；缓存完整后可加`-Offline`。环境配置与报告位置见[SETUP](SETUP.md)。历史模拟器检查产物另行保存，未随源码仓库分发。实际设备验收和生理效果仍待硬件到位。
